# KomputerKing App

![Project Logo](https://github.com/MayaTakenOutOfCode/KomputerKing-App/blob/main/app/src/main/res/drawable/vivid_media.png)

## About the Project

KomputerKing is a team project developed in **Android Studio** as part of a university assignment for the **Mobile Application Programming** course.

### Features

- 👥 Developed mainly by foxie3
- 🔐 User **registration and login system**
- 🗄️ Uses **SQLite** as a local database, automatically created during the application's installation
- 💻 Simulates an **online computer store**
- 📱 Built using native Android development in Android Studio

### Notes

- ❌ Online payments are **not implemented**
- 🛒 This project serves as a **prototype/template** of an e-commerce application rather than a complete commercial product
- 🎓 Created for educational purposes as a semester project

## Technologies Used

- Android Studio
- Java
- SQLite
- XML

## Purpose

The main goal of this project was to learn:

- Android application development
- User authentication
- Working with local SQLite databases
- Team collaboration using Git and GitHub
- Designing a simple e-commerce application
